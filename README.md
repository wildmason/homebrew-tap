# Wildmason Homebrew Tap

Homebrew formulae for Wildmason command-line tools.

## safe-bundle

```sh
brew install wildmason/tap/safe-bundle
safe-bundle --version
```

`safe-bundle` is a local-first redaction and safe support bundle CLI.

## prosaic

```sh
brew install wildmason/tap/prosaic
prosaic --help
```

`prosaic` is a natural language generation CLI for rendering JSON-lines events.
The Homebrew formula currently targets the Linux x86_64 release archive; macOS
Homebrew support will be added once macOS archives are published. On macOS, use
`cargo install prosaic` for now.
